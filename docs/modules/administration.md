# Administration

Users supports searching, status/role filters, pagination, create/edit, status toggle, password reset and soft deletion. Roles supports create/edit, permission matrix presets, and deletion of unassigned custom roles. Actions require matching permissions and administrative role membership.

Settings supports app identity, company contact fields, logo/favicon upload, theme colors, layout/radius and white-label display. Users with only settings.read can view the page; editing controls are disabled. Save actions and uploads require settings.update on the backend.

Home has no seeded statistics or fabricated data. Help Center provides Markdown guides and manual workspace tours.
