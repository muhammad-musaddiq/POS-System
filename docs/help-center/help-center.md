# Help Center

Search Markdown guides, browse categories, and open linked topics. User-facing role, module, workflow and tour guides are visible by default. Developer categories are enabled only when VITE_ENABLE_DEVELOPER_DOCS=true at build time.

The default guide is Getting started. Markdown files are bundled from this starter's docs directory. Keep internal secrets and credentials out of all documentation, including hidden developer sections. The header also provides a manual Start tour action.
