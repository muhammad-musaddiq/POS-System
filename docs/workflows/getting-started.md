# Getting started

Sign in using the account provided by your administrator. Home welcomes the authenticated user. The navigation shows pages your role can access.

Administrators can create roles, select permissions, then create users and assign those roles. Check the role guide before granting administrative access. Use Settings to configure the application name, theme and assets when your role allows updates.

Open Help Center for guides. Use Start tour in the header for a manual walkthrough; the tour includes only permitted steps. Sign out clears your local session. Contact your administrator if credentials or permissions need updating.
